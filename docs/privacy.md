# 隐私说明

Free Ledger 的设计前提：**记账数据属于用户本人，不需要也不能离开设备。**

## 数据存放位置

- 全部业务数据存放在浏览器的 IndexedDB 数据库 `free-ledger` 中。
- 设置项同样存放在该库的 `settings` 表。
- 应用没有账号、令牌、Cookie、LocalStorage 中的业务数据，也没有任何服务端。
- Service Worker 只缓存静态资源（JS / CSS / HTML / 图标），不缓存或上传业务数据。

## 网络行为

- 运行期**不发起任何网络请求**：无字体 CDN、无图片外链、无统计 SDK、无错误上报。
- 生产构建在 `index.html` 注入 Content-Security-Policy：
  `default-src 'self'; script-src 'self'; connect-src 'self'; img-src 'self' data:; ...`
  即使将来误引入外部资源，浏览器也会拦截。
- 可通过浏览器开发者工具 → Network 面板自行验证：除首次加载自身静态资源外无请求。
- 唯一的外部行为是：你主动点击「关于」页里的 GitHub 链接（普通页面跳转，不是 XHR）。

## 数据可控

- **导出**：JSON 全量备份包含全部表，可长期归档；CSV 便于 Excel 查看。
- **导入**：本地解析与校验，不经过任何服务器。
- **删除**：删除流水为软删除，进入「我的 → 回收站」，可恢复或彻底删除，保留 30 天后自动清理；清空数据会删除整个 IndexedDB 并恢复默认账户/分类，需二次确认。
- **微信账单导入**：只解析你手动选择的本机 CSV 文件，解析与导入都在本地完成，不上传；导入的记录默认「未分类」，由你自行修改。
- **持久化存储**：可申请 `navigator.storage.persist()`，并在数据页查看已用空间 / 配额；它降低被回收的概率，但不等于备份。
- **备份提醒**：超过 7 天未导出时首页/「我的」页提示。

## 威胁模型与边界

| 风险 | 说明 | 应对 |
|---|---|---|
| 浏览器数据被清除 | 清理站点数据、无痕模式、系统清理软件 | 定期导出 JSON 备份 |
| iOS PWA 存储回收 | 长期不打开的站点可能被系统回收存储 | 备份提醒 + 导出 |
| 设备丢失 / 他人使用 | 本应用不做应用锁 | 依赖系统锁屏；后续可考虑口令加密 |
| 浏览器扩展 / 恶意脚本 | 可读取页面内数据 | 使用可信浏览器与扩展；生产 CSP 限制脚本来源 |
| 供应链 | 依赖被篡改 | 依赖少、锁文件固定、可自行审计构建 |
| 多设备同步 | 本应用不提供云同步 | 手动导出/导入迁移 |

## 我们不做的事

- 不收集设备信息、使用统计、崩溃日志。
- 不做用户画像、不做广告投放、不做会员订阅。
- 不提供"云备份"功能，也不会悄悄上传数据。
- 不在应用内嵌入任何第三方页面或 SDK。

## 自证方式

1. 阅读源码（本仓库即全部代码，无闭源模块）；
2. 自行 `npm run build` 构建，用 `dist/` 部署；
3. 浏览器 Network 面板确认无外部请求；
4. 断网使用，功能完整。
