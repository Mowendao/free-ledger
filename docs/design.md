# 设计语言：宣纸账簿

目标不是"好看的应用模板"，而是一页**安静、耐用、可长期翻阅的账本**。
因此刻意避开渐变、玻璃拟态、大圆角、彩色图标气泡和仪表盘式卡片堆叠。

## 三色

| 名称 | 色值 | 用途 |
|---|---|---|
| 宣纸 | `#f5efe3` | 页面底色，配极细纸纹 |
| 墨 | `#201d18` | 正文、线条、主按钮（墨底白字） |
| 朱砂 | `#a63a2e` | 唯一强调色：印章、选中、支出、警示 |
| 黛青 | `#2f5157` | 收入 / 正向数字 |

暗色主题为「墨夜」：`#16140f` 底、`#e9e2d3` 字、朱砂提亮为 `#c9674f`。

## 字体

不加载任何外部字体（离线与隐私要求），全部使用系统中文衬线字体：
`Songti SC / STSong / Source Han Serif SC / Noto Serif CJK SC / SimSun`。
数字使用衬线等宽数字（`tabular-nums`），大小写与账目对齐。

## 版式规则

- 1px 细线分栏代替阴影与色块；卡片圆角 4px，按钮 2px，接近纸张裁切。
- 标题左侧一道 3px 朱砂短线，作为"账目栏"的标记。
- 印章元素（白文"账""记"）只用于身份与记账落款，不滥用。
- 分类色板取自传统色：赭石、花青、胭脂、藤黄、竹青、靛青、朱砂、绛、灰。
- 图表为细线环与细柱，图例用方形墨点。
- 底部导航当前项：顶部 2px 朱砂短线 + 朱砂图标，文字转黑。

## 动效

只保留必要的淡入、底部弹层上滑与 Toast；尊重 `prefers-reduced-motion`。
