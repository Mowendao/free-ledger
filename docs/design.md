# 设计语言：四种界面风格

目标不是"好看的应用模板"，而是一本**安静、耐用、可长期翻阅的账本**。
因此刻意避开模板化的渐变、玻璃拟态、大圆角与仪表盘堆叠。

风格系统由两层组成：`data-skin` 选风格，`data-theme` 选明暗（浅色 / 深色 / 跟随系统）。
每个皮肤都定义完整的配色、圆角、字体、阴影与纹理，互不串味；选择保存在本机，并随备份迁移。

## 四种风格

| 风格 | 关键词 | 纸 / 墨 / 强调色 | 字体与形状 |
|---|---|---|---|
| 宣纸账簿 `ink` | 纸墨朱砂、宋体细线 | `#f5efe3` / `#201d18` / `#a63a2e` | 宋体，圆角 4px，纸纹 |
| 墨白 `mono` | 黑白编辑排版 | `#f6f6f4` / `#111111` / `#111111` | 无衬线，直角，无纹理 |
| 青瓷 `celadon` | 莫兰迪青绿 | `#ecf1ed` / `#243029` / `#5c7d6a` | 无衬线，圆角 14px，轻阴影 |
| 牛皮纸 `kraft` | 复古票据、砖红 | `#e8dcc4` / `#2f2619` / `#a8542f` | 宋体，虚线分栏、双线页头 |
| 莫兰迪粉 `rose` | 低饱和玫瑰 | `#f6ece7` / `#3a2f2c` / `#a9736b` | 无衬线，圆角 12px，柔雾 |
| 绿皮火车 `olive` | 军绿米黄、旧车票 | `#eee6d2` / `#2f3a27` / `#7d6a3c` | 宋体，双线页头 |
| 终端 `terminal` | 等宽字符、扫描线 | `#f2f5ec` / `#1f3b26` / `#2f7a4a` | 等宽字体，直角，扫描线纹理 |

## 宣纸账簿（默认）

三色：**纸 `#f5efe3`、墨 `#201d18`、朱砂 `#a63a2e`**；收入用黛青 `#2f5157`。
暗色主题为「墨夜」：`#16140f` 底、`#e9e2d3` 字、朱砂提亮为 `#c9674f`。

- 1px 细线分栏代替阴影与色块；卡片圆角 4px，按钮 2px。
- 标题左侧一道 3px 朱砂短线，作为"账目栏"标记。
- 印章（白文"账""记"）只用于身份与落款。
- 分类色板取自传统色：赭石、花青、胭脂、藤黄、竹青、靛青、朱砂、绛、灰。

## 其他风格的差异

- **墨白**：纯黑白、0 圆角、无阴影，分类图标自动灰度；靠字重、+/− 与留白区分收支。
- **青瓷**：低饱和青绿，10–20px 圆角与极轻阴影，胶囊标签，分类图标降低饱和。
- **牛皮纸**：牛皮纸底色与砖红强调，列表虚线、页头双线，分类图标偏暖。

## 字体

不加载任何外部字体（离线与隐私要求）：

- 宣纸 / 牛皮纸：`Songti SC / STSong / Source Han Serif SC / Noto Serif CJK SC / SimSun`
- 墨白 / 青瓷：系统无衬线 `PingFang SC / Microsoft YaHei / system-ui`

数字统一使用 `tabular-nums`，便于账目对齐。

## 动效

只保留必要的淡入、底部弹层上滑与 Toast；尊重 `prefers-reduced-motion`。
